## DesktopCow For Linux

This is a fan-made adaptation of the DesktopCow for Linux. the original project is from moonrain479, and below I have included the original text for DesktopCow.

## Abstrakt

A simple Desktop-Pet that is driven by Chance. 
The cow can walk, eat, sleep and stare into nothing.

It is an ongoing project I sometimes come back to and add functionality to, just for fun.
